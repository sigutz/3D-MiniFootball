# 3D-MiniFootball

A 3D-printed mini-football arena combined with fast-paced pinball mechanics. 

This project is inspired by the elegant, screwless design of [this mini table football model](https://www.printables.com/model/1422126-elegant-mini-table-football-without-screws), expanding on it with mechanical flippers, modular arena walls, and future expansions.

---

## The Core Mechanism (Flippers)

The primary interactive element of the game is the mechanical gate (flipper) used to strike the plastic ball. It operates using a spring-loaded rack and pinion mechanism.

### 1. The Gate & Gear
The gate features a long cylindrical pivot to anchor it to the table, topped with a hexagonal shaft for a secure, slip-free connection to the driving gear.
<img width="701" height="715" alt="The Gate" src="https://github.com/user-attachments/assets/50c68160-7814-43aa-8c2c-cfb4b4ab1578" />
<img width="646" height="466" alt="The Gear" src="https://github.com/user-attachments/assets/b5de5289-c199-4279-8cc5-a42a506af0cd" />

### 2. The Actuator (Slider & Spring)
A sliding bar (rack) meshes with the gear. Pulling the slider spins the gear, swinging the gate forward. A built-in compression spring sits at the end of the slider, pushing it back to ensure the gate rests in a default "closed" position.

### 3. Mechanism Housing
The entire actuator mechanism is seated inside a custom housing block to keep the slider aligned and the spring contained.
